## About the Project

The vinyl collection page was create as part of the pair lab exercise for the COMP 1235 - Introduction to Full Stack Development course. The exercise consisted of create a webpage considering the knowledge we had been working on throughout the course, where we should rotate between organize the ideas, and implement it by coding/debugging to fit the requirements.

The page was implemented by using intermediate CSS and HTML knowledge, and, specially, using JavaScript by practicing intermediate concepts worked in classes, such as functions, hoisting, async, and regex to name a few.

We could also connect the different web development knowledge, using JS to generate some html page content, and also, implement mouseover/mouseout event on some page elements by adding eventListener. The implementation of a json file for the content information allowed to update the page content easier and faster. The information was used to fetch and render the page main content as well as the menu.

This hands on project was important to practice, learn and connect different areas of a web page, and helped me to consolidate even more some JavaScript knowledge in the context of web development. Most importantly, being able to communicate openly with my team was a vital part for the success of the project development.
